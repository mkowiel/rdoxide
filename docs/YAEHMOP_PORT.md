# YAeHMOP (extended Hueckel) port

`rdoxide.Chem.rdEHTTools` runs extended Hueckel calculations. The Rust code in
`crates/rdoxide/src/external/yaehmop/` ports the molecular path of YAeHMOP's `tightbind` library
(BSD-2-Clause, `LICENSES/YAeHMOP-BSD-2-Clause.txt`) as RDKit's `External/YAeHMOP/EHTTools.cpp` drives it.

| Module | C source | Notes |
|--------|----------|-------|
| `params.rs`, `params_data.rs` | `fileio.c` `fill_atomic_parms`, `eht_parms.h` | table generated by `tools/gen_yaehmop_params.py`; double-zeta d/f renormalisation |
| `overlap.rs` | `abfns.c`, `lovlap.c`, `mov.c`, `R_overlap_mat.c` | s, p, d and f Slater overlaps, 10 A cutoff, upper-triangular storage like the C library |
| `diag.rs` | `cboris.c`, `diag.c` | Cholesky reduction + Householder/QL (own implementation, same eigen-system) |
| `mod.rs` | `R_hamil.c`, `mulliken.c`, `charge_mat.c`, `avg_props.c`, `driver.c` | weighted Hij (1.75), occupations with degenerate HOMO sharing, Mulliken analysis, reduced matrices |

Quirks reproduced on purpose: the Fermi level, the total energy and the net charges go through the
average-properties code, which keeps orbital energies and the charge matrix as `float`; the matrices
returned with `keepOverlapAndHamiltonianMatrices` are upper triangular.

Not ported (not reachable from RDKit): periodic systems, k points, band structures, DOS/COOP, walsh diagrams,
FMO/FCO, charge iteration, symmetry analysis (it only prints), the LAPACK path.

## Verification

`tests/data/yaehmop_eht.json` holds 39 molecules (main group, d-block with double-zeta d, a 22-carbon chain)
recorded from the official wheel by `tools/make_yaehmop_corpus.py`; `tests/python/test_ehttools.py` compares all
results (charges, orbital energies, ROP/charge matrices, Fermi/total energy) to 1e-8. The match is ~1e-12 in
practice, also for f-block elements (Ce, U, Th, Gd) checked ad hoc. Upstream `testEHTTools.py` 5/5 is in the ratchet.
Where the C library calls `fatal()` (no parameters, too many electrons) rdoxide raises `ValueError` instead of
terminating the process.
